# Sounds

All from BigSoundBank (https://bigsoundbank.com, Joseph Sardin, CC0). Downloaded from
`https://bigsoundbank.com/UPLOAD/mp3/<number>.mp3`, then cut and leveled with ffmpeg and numpy
(mono, 22.05 kHz; loops cross-faded so they repeat without a click).
